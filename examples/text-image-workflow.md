# 示例：产品图＋文字重建放鞋动作

本例为说明技能用法编写的示例，不是生成效果展示，也不要求上传任何原视频。

## 交给 Codex 的请求

```text
使用 $one-to-one-video-replica。
分析我提供的参考视频，但生成平台只接收文字和鞋子图片。
我准备上传同款短靴的六张角度图，成片中只出现一双鞋。
开场女顾客拿着鞋放到空柜台上，之后男店员拿起一只查看。
穿着总增高为5.5厘米，不要写成外跟高度。
```

## 可独立复制的首镜头提示词示例

竖屏写实鞋店场景，暖色吊灯照亮木质柜台，窗外是冷蓝色傍晚街景。长黑发成年女性站在柜台左侧，穿棕色外套和浅色内搭；戴棕色鸭舌帽、穿深色衬衫的成年男店员站在柜台右侧。开场柜台中央没有鞋，女性双手分别握着两只短靴的靴筒，向前伸手，把一双鞋轻放到柜台中央；鞋底接触台面后才松手，双手收回，鞋子留在台面上，她抬眼看向店员。鞋款外观依据实际上传的同款多角度产品图，始终只有一双左右脚对应的鞋，不把多张图片变成多双鞋。固定平视双人中景，柔和暖光，轻微鞋底落桌声，无对白、无字幕、无水印。

## 下一镜头需要接住的状态

开场一双鞋已在柜台中央。男店员从中拿起一只查看，另一只留在台面。下一条可复制提示词仍需完整写出人物、鞋款、环境与动作，不能只写“接上一个镜头”。

## 使用前核对

- 上传的确实是提示词所指的鞋图；没有图片时删去图片依赖并补写产品外观。
- 总增高用于产品说明或相关对白，不擅自转成可见鞋跟尺寸。
- 平台能否接受多图、生成对白及指定时长，需要使用时核实；此示例不声明这些能力。
