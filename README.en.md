# 1:1 Video Reconstruction Skill

[中文](README.md) · [Skill instructions](SKILL.md) · [Example](examples/text-image-workflow.md)

Analyze an authorized reference video and compile copy-ready Seedance prompts by shot. Provide any available first-frame, character, or product images. The shot-anchor workflow uses clean first frames and reuses character and product anchors across shots. The skill also supports reshoot blueprints, video editing and extension, and comparison against an existing recreation.
