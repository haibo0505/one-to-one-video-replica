# 视频复刻 Skill：把参考视频拆成独立图文提示词

[English](README.en.md) · [技能正文](SKILL.md) · [使用示例](examples/text-image-workflow.md)

面向小云雀「文字＋图片生成」场景的 Codex 技能。参考视频交给 Codex 分析，生成平台只接收独立完整的文字和你实际上传的图片。

**核心变化：视频负责提供分析依据，提示词负责完整描述生成目标。** 不再用“保留原片”“沿用原声”“按照视频动作”等平台无法执行的指令代替描述。

## 适合谁

- 看中一条视频的镜头与动作，希望拆解后用图文生成重新制作。
- 用自己的产品图替换视频中的商品，需要同步修改结构、数量、颜色和参数。
- 希望拿到逐镜头独立提示词，或一次生成所需的完整多镜头段落。
- 需要参考分析、实拍蓝图，或对已有复刻成片进行差异检查。

## 工作流程

```text
交给 Codex：有权使用的参考视频＋可选产品/人物图片＋修改要求
                         ↓
分析镜头、关键动作、构图、视线、对白与道具状态
                         ↓
编写每条可独立理解的生成提示词
                         ↓
交给小云雀：文字＋实际准备上传的图片
```

分析视频、原音轨、未上传的截图不会被当作生成平台输入。只有明确选择上传参考视频时，才切换到相应工作流。

## 这次修正了什么

| 常见问题 | 新的处理方式 |
| --- | --- |
| “保持原视频动作” | 写出起始姿态、移动过程、接触、松手与结束位置 |
| “原声照旧” | 写出具体对白、说话人和声音设计；未核实的信息单独说明 |
| 顾客放鞋变成柜台本来有鞋 | 检查手中、台面、拿起和放下之间的状态连续性 |
| 六张鞋图生成六双鞋 | 区分图片数量、产品款式数量与成片物体数量 |
| 总增高被改成外跟高度 | 保持用户参数口径，检查各镜头和对白中的冲突 |
| 把别的平台参数套给小云雀 | 不预设时长上限、槽位、音频或口型能力 |

## 安装与使用

下载本仓库 ZIP，解压后保留完整目录结构，或克隆源码：

```powershell
git clone https://github.com/haibo0505/one-to-one-video-replica.git D:\APP\codex-skills\one-to-one-video-replica
```

已有目录时先检查本地改动，不要覆盖。让 Codex 读取该目录中的 `SKILL.md` 即可使用；如需注册到个人技能目录，请按自己的 Codex 配置安装整个技能目录。仓库不附带自动安装器，也不执行个人目录写入。

推荐请求：

```text
使用 $one-to-one-video-replica 拆解我提供的视频。
目标平台是小云雀，只上传文字和产品图片，不上传参考视频或音频。
六张图是同款产品的不同角度，成片中只出现一双鞋。
请写清人物、场景、拿放动作、镜头与对白，每条提示词能独立复制使用。
```

图片可选：没有图片时先根据实际分析材料写文字方案，不虚构图片标签。想换鞋款时，提供实际产品图，并说明颜色、数量和参数。需要一次生成整条时明确说“一次生成”，技能会给出一个完整多镜头段落。

## 输出

默认包括全局画面控制、生成材料说明，以及逐镜头的分析定位、剪辑目标时长、场景、构图、主体、表情、动作、背景、镜头、声音和完整提示词。定位时间不是平台参数。

**1:1 是重建目标，不是生成保证。** 本技能提供分析与提示词规则，不含视频生成模型、自动剪辑引擎或平台接口。视频读取和抽帧等能力由使用环境提供。结构校验不等于真实生成测试；`test-prompts.json` 是人工回归场景，不是已经通过的自动化测试。

## 边界

仅处理你有权使用的素材；不随仓库分发参考视频、人物照片或聊天记录。无法确认的画面、对白和时间应标注，不伪装成实测。准确配音、口型、切点或字幕可结合后期处理。需要实际生成时，应另行授权并确认平台能力。
